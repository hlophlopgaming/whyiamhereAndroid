## English

Fixed the floating widget using the system language when a different app language
was selected on Android 13 and newer. Collapse/Finish buttons, accessibility
descriptions and service error messages now follow the app language. With no app
language override, they continue to follow the system language.

Uses the same permanent signing key as 0.3.0; install over the existing release
without uninstalling to keep your settings, goals and sessions.

Validation: JVM tests, localization checks, release lint, signed release build,
and a manual English-widget check on a Samsung Galaxy S20+ running Android 13.
The regression test covers English, Spanish and resetting to the system language.
It was compiled but has not been executed on the device. Three real-device
English screenshots are now included in the F-Droid store metadata.

## Español

Corregido el widget flotante que usaba el idioma del sistema cuando se había
elegido otro idioma para la aplicación en Android 13 o posterior. Los botones,
las descripciones de accesibilidad y los mensajes del servicio ahora respetan
el idioma de la aplicación. Sin un idioma específico, siguen el del sistema.

La firma es la misma que en 0.3.0. Instala la actualización sin desinstalar
para conservar los ajustes, objetivos y sesiones.

Validación: pruebas JVM, traducciones, lint, compilación firmada y comprobación
manual del widget en inglés en un Samsung Galaxy S20+ con Android 13.
Las pruebas de idioma se compilaron, pero no se ejecutaron en el teléfono.
Se incluyen tres capturas reales en inglés para F-Droid.

## Русский

Исправлен виджет, который оставался на системном языке при выборе другого языка
для приложения на Android 13 и новее. Кнопки, описания для специальных
возможностей и сообщения службы теперь учитывают язык приложения. Без отдельной
настройки языка они следуют системному языку.

Подпись та же, что в 0.3.0. Устанавливайте поверх текущего релиза без удаления,
чтобы сохранить настройки, цели и сессии.

Проверки: JVM-тесты, переводы, lint, подписанная сборка и ручная проверка
английского виджета на Samsung Galaxy S20+ с Android 13.
Автоматический тест языков собран, но на телефоне не запускался. Для F-Droid
добавлены три настоящих скриншота приложения на английском.
