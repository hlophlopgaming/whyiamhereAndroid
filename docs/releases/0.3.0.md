## English

First public release of **Why am I here?** for Android 8.0 and newer.

- Automatically follows the Android language: English, Spanish, or Russian; English is the fallback.
- Choose apps, set a goal and duration, and keep a draggable goal/timer widget on screen.
- Independent app sessions, warning sound, automatic return home, recent goals, and local history.
- Works offline, without root or the “Display over other apps” permission.
- Signed, optimized release APK with SHA-256 checksum; source and release scripts included.

**Installing over the old 0.2.0 debug APK:** uninstall that test build first. Its local goals, settings, and sessions will be deleted. This version introduces a permanent release signing key; future releases will use the same key.

Download `whyiamhere-0.3.0.apk`, install it, select apps, and enable the accessibility service. On Android 13+, you may need **App info → ⋮ → Allow restricted settings** first.

Validation: unit tests, localization resource checks, lint, release APK build and signature verification. Locale and Room device tests are included but were not run on a device. OEM battery restrictions and split-screen/PiP behavior still need device-specific checking. Returning home does not stop background media.

## Español

Primera versión pública de **¿Por qué estoy aquí?** para Android 8.0 o posterior.

- Sigue automáticamente el idioma de Android: inglés, español o ruso; usa inglés para otros idiomas.
- Elige aplicaciones, un objetivo y una duración; mantén visible un widget móvil con el objetivo y el tiempo.
- Sesiones independientes, aviso sonoro, regreso automático al inicio, objetivos recientes e historial local.
- Funciona sin conexión, sin root y sin el permiso “Mostrar sobre otras aplicaciones”.
- APK de lanzamiento optimizado y firmado, con suma SHA-256, código fuente y scripts de publicación.

**Si tienes el APK de prueba 0.2.0:** desinstálalo antes de instalar esta versión. Se borrarán sus objetivos, ajustes y sesiones locales. Esta versión introduce una clave de firma permanente que se usará en futuras actualizaciones.

Descarga `whyiamhere-0.3.0.apk`, instálalo, elige aplicaciones y activa el servicio de accesibilidad. En Android 13 o posterior, puede ser necesario abrir **Información de la aplicación → ⋮ → Permitir ajustes restringidos**.

Validación: pruebas unitarias, comprobación de traducciones, lint, compilación y verificación de la firma del APK. Las pruebas de idioma y Room para dispositivos están incluidas, pero no se han ejecutado en un teléfono. Las restricciones de batería de cada fabricante y los modos de pantalla dividida/PiP necesitan comprobaciones adicionales. Volver al inicio no detiene la reproducción multimedia en segundo plano.

## Русский

Первый публичный релиз **«Зачем я здесь?»** для Android 8.0 и новее.

- Автоматический выбор английского, испанского или русского по языку Android; для остальных языков используется английский.
- Выбор приложений, цели и времени; перетаскиваемый виджет с целью и таймером.
- Независимые сессии, предупреждение со звуком, возврат домой, последние цели и локальная история.
- Работа без сети, root и разрешения «Поверх других приложений».
- Оптимизированный APK с постоянной подписью, контрольной суммой SHA-256, исходниками и скриптами публикации.

**Если установлен тестовый APK 0.2.0:** сначала удалите его. Его локальные цели, настройки и сессии будут удалены. Начиная с этого релиза используется постоянный ключ подписи для будущих обновлений.

Скачайте `whyiamhere-0.3.0.apk`, установите, выберите приложения и включите службу специальных возможностей. На Android 13+ сначала может потребоваться **О приложении → ⋮ → Разрешить ограниченные настройки**.

Проверки: юнит-тесты, ресурсы переводов, lint, сборка и подпись APK. Тесты языков и Room для устройств добавлены, но на телефоне не запускались. Ограничения батареи разных прошивок и режимы разделённого экрана/PiP требуют ручной проверки. Возврат домой не останавливает фоновое воспроизведение.
