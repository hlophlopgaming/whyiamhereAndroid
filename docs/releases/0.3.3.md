## English

Fixed APK packaging for F-Droid: release APKs no longer contain encrypted dependency metadata in the signing block.

Uses the same permanent signing key as previous releases. Install over an existing release to keep your settings, goals, and sessions.

## Español

Corregido el empaquetado del APK para F-Droid: los APK de lanzamiento ya no contienen metadatos cifrados de dependencias en el bloque de firma.

Se conserva la clave de firma permanente. Puedes actualizar sin perder tus ajustes, objetivos ni sesiones.

## Русский

Исправлена упаковка APK для F-Droid: релизные APK больше не содержат зашифрованные метаданные зависимостей в блоке подписи.

Постоянный ключ подписи сохранён. Обновление поверх предыдущей версии сохраняет настройки, цели и сессии.
