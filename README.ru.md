# Зачем я здесь? — Android

[English](README.md) · [Español](README.es.md) · [Русский](README.ru.md)

Небольшой помощник для осознанного использования приложений. Перед открытием
выбранного приложения запиши, что хочешь сделать и сколько времени нужно.
Плавающий виджет напоминает о цели; по окончании времени приложение возвращает
на главный экран. Всё работает локально на телефоне.

**[Скачать последний APK](https://github.com/hlophlopgaming/whyiamhereAndroid/releases/latest)** · [Лицензия MIT](LICENSE)

## Возможности

- Выбор установленных приложений с поиском и иконками.
- Цель и длительность: 5, 15, 30 минут или своё значение.
- Перетаскивание и сворачивание виджета; досрочное завершение сессии.
- Независимые таймеры, включая время в других приложениях и при выключенном экране.
- Настраиваемое предупреждение; в беззвучном режиме — визуальное.
- Последние цели, локальная история и восстановление сессий после перезапуска.
- Русский, английский и испанский по языку Android; для остальных языков — английский. Введённые цели не переводятся.

**Android 8.0+ · Без разрешения на интернет · Без root · Без аккаунта · Без разрешения «Поверх других приложений».**

## Установка

1. Скачайте `.apk` из [Releases](https://github.com/hlophlopgaming/whyiamhereAndroid/releases).
2. Откройте его на телефоне и разрешите установку из этого источника, если Android попросит.
3. Откройте **«Зачем я здесь?»**, выберите приложения и нажмите **«Открыть настройки службы»**.
4. Включите службу специальных возможностей и проверьте статус **«Работает»**.

На Android 13+ перед включением службы может потребоваться **О приложении → ⋮ → Разрешить ограниченные настройки**. Названия меню зависят от прошивки. Если служба останавливается, разрешите автозапуск и уберите ограничения батареи.

**Переход с тестового APK 0.2.0 на 0.3.0:** сначала удалите старую версию.
Её локальные данные будут удалены. Начиная с 0.3.0 используется постоянная
релизная подпись; следующие версии будут обновляться с тем же ключом.

## Приватность и ограничения

Настройки, цели и сессии остаются в хранилище приложения на телефоне. Резервное
копирование и перенос данных отключены. Удаление приложения удаляет данные.
Служба получает пакет активного окна; она не читает тексты, пароли или сообщения
с экрана. Разрешение на интернет не запрашивается.

Это добровольный помощник: службу можно отключить, а выбранное приложение может
кратко появиться до формы. Возврат домой не останавливает фоновое аудио или видео.
Изменение часов телефона изменит таймер. Предупреждение и виджет обновляются,
пока выбранное приложение видно; истечение в фоне обрабатывается при возвращении.
Переподключение службы может повторить звук предупреждения. В разделённом экране
и PiP используется активное окно. Ограничения батареи разных прошивок требуют
проверки на вашем устройстве.

## Сборка и тесты

Kotlin, Jetpack Compose Material 3, AccessibilityService, Room и Preferences
DataStore. minSdk 26, compile/target SDK 37.

Нужны JDK 17, Android SDK Platform 37.0 и Build Tools 36.0.0. Задайте
`JAVA_HOME` и `ANDROID_HOME` либо используйте Android Studio и локальный `sdk.dir`.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
python3 scripts/check-locales.py
```

Тестовый APK: `app/build/outputs/apk/debug/app-debug.apk`.
Юнит-тесты проверяют сессии, истечение, независимые таймеры, восстановление,
фильтр пакетов, предупреждения и формат времени. Тесты для устройств проверяют
историю Room и выбор ресурсов языка, включая испанские регионы и английский
язык по умолчанию:

```sh
./gradlew connectedDebugAndroidTest
adb logcat -s WhyService
```

Для получения пакета активного окна используется `canRetrieveWindowContent=true`.
Код не обходит текстовые узлы и не делает снимки экрана.
[Документация Android](https://developer.android.com/reference/android/accessibilityservice/AccessibilityServiceInfo).

## Релиз

См. [инструкцию выпуска](docs/RELEASING.md). Скрипт проверяет переводы, запускает
тесты и lint, собирает подписанный оптимизированный APK и его SHA-256.
При публикации создаёт тег версии и проверяет загруженный APK, прежде чем
сделать релиз GitHub публичным.

```sh
scripts/release.sh 0.3.0 --prepare
scripts/release.sh 0.3.0 --publish
```

Храните постоянный ключ и пароли вне Git и сделайте резервную копию.
В релизной сборке включены R8 и сокращение ресурсов.

## Ручная проверка

Проверьте открытие из лаунчера, недавних и уведомлений; отмену формы; перемещение
и сворачивание виджета; независимые таймеры; истечение на экране и в фоне;
досрочное завершение; беззвучный режим; блокировку экрана; перезагрузку;
смену языка Android; очистку истории; отключение и переподключение службы.
Проверьте несколько прошивок, прежде чем рассчитывать на одинаковое поведение.
Графики, расписания, экспорт данных и Google Play не входят в MVP.
